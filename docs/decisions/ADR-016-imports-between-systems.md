# ADR-016. Ссылки между системами — лёгкий `imports`

**Статус.** Принято 25.10.2026 (развилка Q7; Кирилл — за лёгкий механизм, принято).

**Контекст.** Один `system_id` на пять файлов. Продукт из нескольких систем с общими сущностями либо описывался одной системой, либо дублировал сущности.

**Решение.**
1. В `domain.json` — `imports: [{system_id, entities[], source?}]`.
2. Импортированная сущность допустима в `ref`, `relations`, `touches_entities`, `applies_to`, `scope.entity`.
3. Импортированная сущность **не** допустима в `transitions` и `aggregate_entity`: состоянием владеет ровно одна система.
4. Проверка существования импорта в чужом репозитории — вне валидатора (drift другой системы).

**Почему так.** Достаточно, чтобы не дублировать описания; при этом нельзя случайно завести два владельца одного автомата.

**Последствия.** Схема `domain`: `imports`. Валидатор: известные сущности = свои + импортированные, с ограничением п. 3.
