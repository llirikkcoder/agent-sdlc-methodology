# ADR-012. Судья даёт оценки; решение гейта детерминировано

**Статус.** Принято 25.10.2026 (развилка Q3; позиции совпали).

**Контекст.** Можно ли позволить `llm_step` возвращать решение `approve/reject` напрямую.

**Решение.** Нет. Шаг модели-оценщика возвращает только оценки (числа, метки, обоснование). Решение принимает детерминированная функция с порогами, описанными в ограничении слоя 1 (`threshold`) или в описании шага. В журнале: `StepCompleted` судьи с оценками и `metadata.model {name, version, prompt_version}`, затем отдельное событие решения (`HumanGateRequested`, `AutoApprovedByRule` или доменное).

**Почему так.** Воспроизводимость для аудита: при тех же оценках решение одинаково; смена модели меняет оценки, но не правило. ADR-010 опирается на то же: порог — по детерминированным данным.

**Последствия.** Документы 02 и 03 уточнены. Схемы не меняются: `llm_step` уже не может быть `capability_id` с `human_gate` в роли решения — проверяется правилом гейта.
