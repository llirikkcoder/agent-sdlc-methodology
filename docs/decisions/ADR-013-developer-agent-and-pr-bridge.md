# ADR-013. Два цикла; мост — агент-разработчик с человеческим ревью на слияние

**Статус.** Принято 25.10.2026 (развилка Q4; позиции совпали).

**Контекст.** ADR-007 разделил исполнение и поставку. Исходник описывал конвейер «промпт → изменения в коде», в котором агент сам меняет код.

**Решение.**
1. Два цикла остаются.
2. Добавлена роль **агента-разработчика**: обнаружив `CapabilityMissing` или `DriftDetected`, он проходит цикл поставки как исполнитель — меняет код **и** слои (манифесты), прогоняет `validate` и `drift`, открывает запрос на слияние.
3. Слияние — безусловный человеческий гейт. Размер правки роли не играет.
4. Возможности «изменить код», «применить миграцию», «изменить права» — `system_level: true` (ADR-011).

**Почему так.** Агент-оператор и агент-разработчик — разные права; один конвейер смешал бы их. PR-ревью уже существует в любой команде, и это самый дешёвый гейт.

**Последствия.** Документ 03: раздел «Мост между циклами». Отдельной схемы для PR не вводится: PR — это `HumanGateRequested/Resolved` в цикле поставки.
