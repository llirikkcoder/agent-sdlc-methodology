# ADR-015. Чтения — только итог; шаги модели — полный лог

**Статус.** Принято 25.10.2026 (развилка Q6; позиции совпали, Кирилл уточнил обязательность `model` и `prompt_version`).

**Решение.**
1. Шаги с `effect: read` (кроме `llm_step`): один `StepCompleted` с агрегатом или хэшем результата. `StepRequested` не обязателен.
2. Шаги `kind: llm_step` (судьи, классификаторы, генерация): всегда `StepRequested` и `StepCompleted`; `metadata.model.name` обязателен (ошибка валидатора), `metadata.model.prompt_version` — предупреждение при отсутствии. Вход и выход — в `payload` по ссылке или хэшем, если содержат чувствительные данные.

**Почему так.** Чтения многочисленны и воспроизводимы по данным; вызов модели — нет: без модели и версии промпта его нельзя ни повторить, ни объяснить аудитору.

**Последствия.** Валидатор: проверка `metadata.model` у событий шагов `llm_step`. Пример regulated-document-qa: `prompt_version` у `DraftGenerated`.
