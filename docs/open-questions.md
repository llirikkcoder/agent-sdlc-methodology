# Развилки по сути методологии — решены

Восемь вопросов были собраны при сборке (25.10.2026) и не решались самостоятельно. В тот же день Кирилл делегировал решение («по твоему усмотрению») и прислал свои предложения. Ниже — вопрос, позиция Кирилла, что принято, и ADR с подробностями.

| № | Вопрос | Предложение Кирилла | Принято | ADR |
|---|---|---|---|---|
| Q1 | Необратимое действие ниже порога: всегда человек? | Условный гейт по детерминированному порогу из данных сущности; автопрохождение фиксировать событием | Принято целиком: `threshold` у ограничения, `AutoApprovedByRule` | [ADR-010](decisions/ADR-010-threshold-gate-on-irreversible.md) |
| Q2 | Нужен ли `write_compensable`? | Четыре класса; компенсация обязательна, выполняется системой (сага); отдельно — действия над самой системой | Принято; «действия над системой» — флаг `system_level`, не пятый класс | [ADR-011](decisions/ADR-011-four-effect-classes-and-system-level.md) |
| Q3 | Судья как гейт? | Только скоринг; решение детерминировано | Совпало | [ADR-012](decisions/ADR-012-judge-is-not-a-gate.md) |
| Q4 | Один конвейер или два цикла? | Два цикла; мост — агент-разработчик с PR и человеческим ревью | Совпало | [ADR-013](decisions/ADR-013-developer-agent-and-pr-bridge.md) |
| Q5 | Очередь человека: проекция или сущность? | Первичная сущность, но каждый переход порождает событие | Принято; добавлен `HumanGateClaimed` | [ADR-014](decisions/ADR-014-queue-as-entity-with-mandatory-events.md) |
| Q6 | События чтения | Чтения — только `StepCompleted` с агрегатами; `llm_step` — полный лог с моделью и версией промпта | Совпало; `model` обязателен, `prompt_version` — предупреждение | [ADR-015](decisions/ADR-015-read-events-and-full-llm-log.md) |
| Q7 | Несколько `system_id` | Лёгкий `imports` | Принято (я склонялся к «пока нет») | [ADR-016](decisions/ADR-016-imports-between-systems.md) |
| Q8 | Политика `unconfirmed` | critical блокирует, high предупреждает, medium информирует | Принято; блок — в runtime Static Guard (`--strict`), в поставке — WARN | [ADR-017](decisions/ADR-017-unconfirmed-by-severity.md) |

Расхождения с предложениями Кирилла — только в форме (Q2: флаг вместо класса; Q8: где именно блокировать). Суть везде принята.

## Что остаётся открытым

Новых развилок по сути методологии нет. Предметные вопросы примеров (например, где хостится модель для C007 в regulated-document-qa) — в README соответствующих примеров.
